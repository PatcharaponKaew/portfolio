## 🌟 Overview

Welcome to the source code of my personal portfolio website. Designed and built with a modern, high-performance web architecture focused on clean typography, fluid responsive design, interactive storytelling, and enterprise-grade security.

👉 **Live Website:** [https://patcharapon-portfolio.vercel.app](https://patcharapon-portfolio.vercel.app)

---

## ✨ Key Highlights

- **⚡ Modern Stack:** Built with Next.js 15 (App Router), React 19, and TypeScript.
- **🎨 Custom Design System:** Handcrafted fluid CSS design system with smooth micro-interactions, responsive scaling, and zero unnecessary bloat.
- **🛡️ Enterprise-Grade Security:**
  - Configured with strict **HTTP Security Headers** (`X-Frame-Options`, `HSTS`, `nosniff`, `Permissions-Policy`).
  - Concealed platform fingerprints (`poweredByHeader: false`).
  - No external sensitive secrets or vulnerable database backends.
- **🐱 Interactive Mascot Component:** Lightweight, responsive canvas mascot with interactive cursor tracking and playful state reactions.
- **🎠 60 FPS Project Carousel:** Seamless 90% / 100% / 90% card focus with touch swipe, dragging, and auto-pause accessibility.
- **✈️ Travel-Inspired Boarding Pass Experience:** Dynamic visualization of international leadership and educational journeys across Japan, Taiwan, Singapore, South Korea, and the US.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (version 18.18 or higher recommended)
- npm or yarn / pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PatcharaponKaew/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
npm run build
npm run start
```

## 🔒 Security Audit & Hardening

This project adheres to modern web application security best practices:
- **Clickjacking Defense:** Frame embedding restricted via `X-Frame-Options: DENY`.
- **MIME Sniffing Prevention:** Enforced `X-Content-Type-Options: nosniff`.
- **Strict HTTPS Enforcement:** HSTS with `max-age=63072000; includeSubDomains; preload`.
- **Device Privacy Protection:** Strict `Permissions-Policy` disabling camera, microphone, and geolocation by default.
- **Dependency Cleanliness:** Audited and resolved vulnerable transitive dependencies.
